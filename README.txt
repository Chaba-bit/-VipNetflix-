# VipNetflix Mobile

Versão que funciona sem Node.js: basta extrair e abrir `index.html` no navegador do celular.

## Como usar no Android
1. Baixe e extraia o ZIP.
2. Abra a pasta `VipNetflix_Mobile`.
3. Toque em `index.html`.
4. Escolha Chrome (ou outro navegador).
5. O protótipo funciona offline.

## Inclui
- Início
- Explorar e pesquisa
- Detalhes
- Player de demonstração
- Minha Lista
- Perfil
- Login/cadastro local de demonstração
- Planos
- Interface responsiva para celular

## Nota
Este é um protótipo académico. O login e os dados ficam no armazenamento local do navegador. Pagamentos e streaming real ainda não estão ligados a serviços externos. Use somente conteúdo para o qual tenha direitos.
